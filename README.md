# site

個人サイト

## コマンド

| コマンド       | 内容                                       |
| :------------- | :----------------------------------------- |
| `pnpm install` | 依存パッケージをインストール               |
| `pnpm dev`     | 開発サーバーを `localhost:4321` で起動     |
| `pnpm build`   | `./dist/` に本番用ビルドを出力             |
| `pnpm preview` | ビルド結果をローカルで確認                 |
| `pnpm check`   | 型と Astro テンプレートの検査              |
